## Scope and gaps

- Scripted runs cover buyer order placement, member registration/approval, and leader order creation for all three current languages with rule-based extraction and a fake NLU wrapper.
- The webhook's Twilio signature, actual voice transcription, production Twilio delivery, and a live SSE connection are not invoked by this isolated runner; existing application tests cover parts of those integrations.
- The catalog check verifies translation keys and placeholder parity. The AST scan is a review aid, not a proof that every dynamic user-facing string is catalog-backed.
- Hindi and Hinglish examples are not native-speaker verified.
